
## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

Copy `.env.example` to `.env` and add your hosted Supabase project values first. For Ubuntu/Docker deployment, see [DEPLOY_VPS.md](./DEPLOY_VPS.md).
